# COMP 484 HTML Reference Site

**GitHub Pages website:** [https://killerpigwolf.github.io/comp484-hw1/](https://killerpigwolf.github.io/comp484-hw1/)

To publish the website, open [this repository's GitHub Pages settings](https://github.com/killerpigwolf/comp484-hw1/settings/pages). Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/ (root)**, and click **Save**. Once deployment finishes, the website link above will open the site.

This repository contains my COMP 484 HTML formatting assignment. The project is a reference site covering introductory HTML concepts.

## Assignment work

- Organized page content with headings and paragraphs
- Added controlled line breaks and text emphasis
- Displayed named HTML character entities
- Inserted and positioned images with accessible alternative text

## Pages

- `index.html` — Introduction to HTML and its history
- `syntax.html` — HTML syntax
- `links.html` — Creating links
- `reference.html` — HTML terms and character entities
- `next.html` — Learning advice and resources
- `structure.html` — HTML document structure
